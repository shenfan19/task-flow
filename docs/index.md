# Tasks Flowchart manual

Each page covers one part of the plugin. Open the page for what you want to do.

| I want to | Page |
|---|---|
| Connect tasks, delete a link, add a linked task, rename an id | [Links and new tasks](links.md) |
| Edit a task, set tags and priority, open its note, change many tasks at once | [Editing tasks](editing.md) |
| Mark the tasks that matter, follow one task's whole chain | [Highlight and focus](highlight_focus.md) |
| Arrange the graph, use the date axis, keep links apart, fit the graph on screen | [Arranging the graph](arranging.md) |
| Put tasks of one tag, note or priority in a column | [Lanes](lanes.md) |
| Hide tasks, save settings as profiles, change colors and sizes | [Filters, profiles and style](filters_profiles_style.md) |
| Understand why a link is straight or slanted | [How Layout arranges nodes](layout_stability.md) |

The controls are at the top left of the view. **Layout**, **Overview** and **Reset** are buttons, and below them the **Profile** row and the folded cards **View**, **Filters** and **Style**. Click a card's title to open it.
