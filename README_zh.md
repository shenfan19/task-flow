# FlowyTask

一个基于树状结构和动态连线关系的可视化任务管理工具，旨在让复杂的工作流变得清晰直观。

## 🌟 核心理念 

传统的待办事项（To-Do）列表通常是线性和平级的，这往往无法体现出大型项目或复杂工作流真实的网状及嵌套结构。**FlowyTask** 试图通过将任务转化为一张**动态的树状/网状节点图**来解决这一痛点。

在这个图形化界面中，你可以自由地建立子任务，以及任务之间的承接和依赖关系。这种所见即所得的“连线”方式，让任务谁先谁后、哪里卡住了变得一目了然，帮助你理清达成最终目标的最佳路径。

## ✨ 核心特性

- **🌳 树状任务架构**: 拒绝枯燥的列表，用无限层级的节点拆解庞大的目标，把大块工作细分为立即可执行的微粒。
- **🔗 动态依赖连线**: 视觉化连接不同任务节点。直观看出某个任务的产出是如何流入并解锁下一个关键任务的。
- **👁️ 可视化交互画板**: 像画思维导图或操作节点编辑器一样，在一个空间化的画布里编排你的任务进度。
- **⚡ 状态智能向上汇总**: 父级节点的完成度会根据其所有子代及依赖任务的当前状态，进行自动、动态的推算和更新。

## 🎯 为什么这样设计？

在面对复杂任务时，人类的大脑更擅长处理空间关系而非线性文字。可视化的操作界面能让你瞬间聚焦核心问题：
1. **是什么在阻塞整体进度？** (通过依赖连线发现瓶颈)
2. **我现在立刻能着手做什么？** (找出那些前置条件都已满足的激活节点)
3. **宏观目标的整体进度怎样了？** (查看根节点动态汇总的进度条)

让工作流(Flow)可视化，让任务(Task)更简单。
